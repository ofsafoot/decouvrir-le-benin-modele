1. Le projet

« Découvrir le Bénin » présente mon pays en quatre pages : l'accueil, Histoire et patrimoine, Nature et paysages, et une galerie photo. J'ai construit le site à partir du modèle gratuit Massively. J'ai d'abord publié le modèle sans rien changer pour le tester avec les validateurs, puis je l'ai adapté et corrigé. Les deux étapes sont visibles dans l'historique Git.

3. Les problèmes d'accessibilité rencontrés

Avant de modifier quoi que ce soit, j'ai passé le modèle dans WAVE, dans le validateur du W3C et dans axe. WAVE trouvait 9 erreurs, 15 erreurs de contraste et 11 alertes, pour un score AIM de 4,7 sur 10.

Après les corrections, WAVE ne trouve plus aucune erreur ni erreur de contraste sur les quatre pages, avec un score AIM de 10 sur 10. Il reste une seule alerte par page : la balise <noscript> du modèle. Je l'ai gardée volontairement : elle charge une feuille de style de secours qui affiche le fond et l'introduction quand JavaScript est désactivé. Sans elle, ces visiteurs verraient une page en partie vide.

4. Validation W3C

Les quatre pages passent le validateur HTML du W3C sans erreur ni avertissement. Sur le modèle d'origine, l'accueil donnait 31 messages et la page generic une erreur.

Les deux feuilles de style passent le validateur CSS. Pour main.css, il reste 285 avertissements : ce sont les préfixes navigateur du modèle (-webkit-, -moz-, -ms-), qui ne sont pas des erreurs. benin.css n'a ni erreur ni avertissement.

5. Un site réactif

Massively est déjà réactif : il utilise des media queries et un menu latéral sur les petits écrans. J'ai vérifié que mes ajouts suivent le même comportement. Par exemple, les miniatures de la galerie passent de 2 colonnes sur mobile à 4 colonnes à partir de 737 px.

6. Mes quatre extras

Extra 1 : une galerie photo interactive en JavaScript

Sur la page Galerie, une photo s'affiche en grand avec son texte alternatif quand on passe la souris sur une miniature. Au clavier, une boucle ajoute tabindex="0" à chaque miniature au chargement de la page, puis onfocus et onblur appellent les mêmes fonctions que la souris.

function upDate(previewPic) {
  let image = document.getElementById("image");
  image.innerHTML = previewPic.alt;
  image.style.backgroundImage = "url('" + previewPic.src + "')";
}

function addTabFocus() {
  console.log("Page chargée : ajout de tabindex sur les photos");

  let photos = document.querySelectorAll(".preview");
  for (let i = 0; i < photos.length; i++) {
    photos[i].setAttribute("tabindex", "0");
  }
}

Extra 2 : une carte OpenStreetMap intégrée

La page Nature se termine par une carte interactive qui situe le Bénin, avec un marqueur au centre du pays. L'iframe a un titre pour les lecteurs d'écran, et elle ne se charge que lorsqu'on approche de la carte (loading="lazy").

<iframe title="Carte du Bénin sur OpenStreetMap" loading="lazy"
  src="https://www.openstreetmap.org/export/embed.html?bbox=0.6%2C6.0%2C4.0%2C12.5&amp;layer=mapnik&amp;marker=9.3%2C2.3"></iframe>

Extra 3 : une frise chronologique en CSS

La page Patrimoine présente quelques dates clés sous forme de frise. C'est une simple liste ordonnée <ol>, donc elle reste lisible par un lecteur d'écran. Le trait vertical et les points sont dessinés en CSS avec border-left et le pseudo-élément ::before.

.frise {
  margin: 0 0 2rem 0.5rem;
  padding: 0 0 0 1.5rem;
  border-left: 4px solid #18bfef;
  list-style: none;
}

.frise li::before {
  content: "";
  position: absolute;
  top: 0.45rem;
  left: -2.15rem;
  width: 1rem;
  height: 1rem;
  border: 3px solid #18bfef;
  border-radius: 50%;
  background-color: #ffffff;
}

Extra 4 : respect du réglage « réduire les animations »

Le modèle fait bouger l'image de fond pendant le défilement (parallaxe) et anime le défilement du bouton « Continuer ». Pour les personnes qui ont activé « réduire les animations », j'ai modifié main.js pour couper ces effets, et ajouté une règle dans benin.css pour les transitions et animations.

var reduceMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

$('.scrolly').scrolly({
  speed: (reduceMotion ? 0 : 1000)
});

$wrapper._parallax(reduceMotion ? 0 : 0.925);
@media (prefers-reduced-motion: reduce) {
  #wrapper > .bg {
    transform: none !important;
  }

  *,
  *::before,
  *::after {
    animation: none !important;
    transition: none !important;
  }
}

7. Comment tester

  • Réactif : réduire la largeur de la fenêtre, ou F12 puis Ctrl+Maj+M.
  • Clavier : appuyer sur Tab dès le chargement pour voir le lien d'évitement, puis parcourir les miniatures de la galerie.
  • Mouvement réduit : F12, menu ⋮, More tools, Rendering, « Emulate CSS media feature prefers-reduced-motion » : le fond ne bouge plus au défilement.
